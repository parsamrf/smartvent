Features

What it does

Two sensor nodes, one gateway and a cloud backend, working together so nobody has to touch a switch.

Automatic control

Each node measures temperature and humidity every 5 seconds and runs its own fan, with hysteresis so it never flickers, even with no connection.

Manual override

Take over any fan from the dashboard, change thresholds, or hand control back to Auto. You see the node's own reply, not just a promise.

Survives outages

If the internet drops, the gateway keeps collecting readings from both nodes and uploads them with their original timestamps when it comes back.

Secure by design

HTTPS everywhere, mutual-TLS from the gateway to AWS, and a login check on every action. You can only see and control your own nodes.

Live history

Gauges, charts from 15 minutes to 24 hours, and a record of every reading, including the ones recovered after an outage.

Ask your devices

A read-only device assistant answers questions like "which room is warmest?" using your real readings, and says so when it doesn't know.

Hardware

Inside the hardware

Three layers: a small sensor node in each room, one gateway that bridges Bluetooth to the internet, and a serverless backend in AWS.

× 2 · one per room

Sensor node

A nice!nano board (Nordic nRF52840) reads a Sensirion SHT31 over I²C every 5 seconds, runs the auto rule locally and drives three status LEDs.

  • RadioBluetooth LE peripheral, 20-byte notifications
  • FirmwareZephyr RTOS · nRF Connect SDK
  • IdentityUnique device ID from chip registers
× 1 · the bridge

BLE gateway

An ESP32-S3 connects to both nodes as a BLE central, publishes each reading to AWS IoT Core and routes commands back to the right node by device ID.

  • UplinkMQTT over mutual TLS, port 8883
  • OfflineRAM ring buffer, about 30 min for two nodes
  • Commands8-byte BLE write to one node only
Serverless · AWS

Cloud backend

IoT rules store every reading in DynamoDB. API Gateway and Lambda serve the dashboard, check your login with Cognito and publish commands back to the gateway.

  • StorageLatest status + full reading history
  • APIHTTPS REST with JWT authorization
  • DeployInfrastructure as code with AWS SAM
